# BIOS, Firmware & Hardware Diagnostics

## Project Overview

This project documents my hands-on experience configuring BIOS/UEFI firmware, troubleshooting hardware stability, and optimizing computer system configurations.

Through personal computer maintenance and troubleshooting, I have worked with firmware settings, memory configurations, system security features, and hardware performance adjustments.

Experience working with BIOS/UEFI settings, including:

- Enabling and configuring Secure Boot.
- Configuring TPM 2.0 and firmware TPM (fTPM).
- Managing system firmware settings.
- Configuring memory profiles and system settings.
