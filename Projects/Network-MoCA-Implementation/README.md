# Household Network Infrastructure & MoCA Implementation

## Project Overview

This project documents my experience improving the networking infrastructure and wireless coverage within my household.

The project involved configuring Wi-Fi range extenders and implementing a MoCA (Multimedia over Coax Alliance) connection to use existing coaxial cabling as a network connection.

## Network Configuration

Work performed included:

- Set up and configured a household Wi-Fi network.
- Installed and configured Wi-Fi range extenders to expand wireless coverage.
- Implemented a MoCA system using existing coaxial cable infrastructure.
- Connected networking equipment through MoCA adapters to establish wired network connectivity.
- Integrated the wired connections with the existing router and network equipment.

## Performance Improvements

Following the implementation, I observed a substantial improvement in network performance.

Reported improvements included:

- Approximately threefold improvement in connection speeds.
- Speeds approaching the household internet plan's advertised 1 Gbps capacity.

Exact speed-test measurements and testing conditions have not yet been documented.

## Technical Skills Demonstrated

- Home network configuration
- Wi-Fi range extension
- MoCA networking
- Coaxial cable infrastructure
- Wired Ethernet connectivity
- Network equipment installation
- Network performance evaluation
- Basic network troubleshooting

## Project Results

Successfully expanded household wireless coverage and implemented wired network connectivity using existing coaxial infrastructure.

The project provided practical experience integrating wired and wireless networking technologies to improve household network performance.
